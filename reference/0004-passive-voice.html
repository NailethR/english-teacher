REF 0004Voz pasiva — detector y tabla completa

File 6A · Grammar Bank p.142. Para reconocerla en un texto y para formarla en cualquier tiempo.

1. Detector en 3 preguntas

  1. ¿Hay be justo antes del verbo? am · is · are · was · were · be · been · being (o contraído: 's, 're, 'm). No hay → activa.
  2. ¿Lo que sigue es V3 (participio), no -ing? is made = pasiva · is making = activa.
  3. ¿El sujeto recibe la acción? Si puedes agregar by someone → pasiva.

Regla de oro: been / being + V3 = siempre pasiva. been / being + -ing = siempre activa.

3. Fórmula y tabla (verbo shoot – shot – shot)

be (en el tiempo de la activa) + V3. Solo cambia be; el V3 nunca cambia. Negativa y pregunta: igual que la activa, con el primer auxiliar.

4. Cuándo usarla y cuándo poner by

  • No se sabe, no importa o es obvio quién lo hizo → pasiva sin by: My laptop is being repaired.
  • Quién lo hizo es información importante → con by: Love in the Time of Cholera was written by García Márquez.
  • Procesos, noticias, lenguaje formal: Many buildings have been damaged by the earthquake.
  • Pasivas fijas del vocabulario de cine: be set in · be based on · be directed by · be shot on location · be dubbed into.

5. Los 4 errores que más bajan nota

  1. Infinitivo o V2 en vez de V3: ✗ was shoot / is being wrote → ✓ was shot / is being written.
  2. Concordancia de be con el sujeto nuevo: ✗ A lot of movies is made → ✓ are made.
  3. Usar do/did en la pasiva: ✗ didn't be released → ✓ wasn't released.
  4. Olvidar been o be: ✗ has stolen / will announced → ✓ has been stolen / will be announced.
